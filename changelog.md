# Changelog

## 2.4.5-test
- Adicionada configuração de ícone por compartilhamento via JSON: `icon`.
- Opções de ícone: `folder`, `contact` e `public`.
- Interface `/meshdrive` agora possui seleção de ícone no cadastro/edição do compartilhamento.
- O plugin tenta criar `desktop.ini` e arquivos `.ico` dentro da pasta física do compartilhamento para facilitar a personalização visual no Windows Explorer.
- Mantido `/drive` com arquivos pessoais diretamente na raiz e compartilhamentos como pastas virtuais.
- Mantido `/carddav` separado e funcional.
- Mantidas proteções da 2.4.2: logs desligados por padrão, trava de handlers e limite de CardDAV REPORT.
